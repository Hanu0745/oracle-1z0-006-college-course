# Answers — Day 11 — Reading Data: SELECT and WHERE

Use this only after you have tried the questions yourself.

**Answers:** 1-C, 2-C, 3-B, 4-C, 5-C, 6-B, 7-B, 8-B, 9-B, 10-B
Why: **4** — NULL is unknown, so `= NULL` is never true; only `IS NULL` works. **5** — unknown plus 5 is still unknown. **10** — Oracle reads NOT, then AND, then OR; use brackets to change it.
