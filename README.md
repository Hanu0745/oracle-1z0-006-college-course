# Oracle Database Foundations (1Z0-006) — College Course

Class material for the 15-day Oracle Database Foundations course. One file is added to `days/` after each class.

## How to use this repo

1. Open the file for today's class in `days/`. It starts with the topic list, then the explanation, examples and practice.
2. Practice in **Oracle Live SQL**: https://livesql.oracle.com (free; sign in with an Oracle account from https://profile.oracle.com).
3. Days 1–8 are theory: you need a notebook and a pencil, not a laptop. Days 9–15 are SQL: bring a laptop.
4. On Day 10, build the practice database once: open `sql/College_Database_Script.sql`, paste it into Live SQL, click **Run**, then **Save** it as `College_DB`. Re-run it any time you want fresh data.
5. Do the 10 MCQs and the homework at the end of each day. Answers are published in `answers/` after the class.
